# Customer Churn Analysis & Business Intelligence

An end-to-end data analysis project investigating customer churn patterns, calculating key SaaS metrics, and identifying high-risk customer segments using Python and SQL.

---

## 📌 Project Overview
Customer churn is one of the most critical metrics for subscription-based businesses. This project extracts customer data from a relational SQLite database, performs rigorous data cleaning and feature engineering, and conducts exploratory data analysis (EDA) to uncover the primary drivers behind customer loss and revenue at risk.

---

## 🛠️ Tech Stack
* **Language:** Python 
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Database:** SQLite
* **Environment:** Jupyter Notebook
